# 隐私与数据

FreeRead 是本地优先的：文献库、解析结果、译文、总结、问答、知识图谱和批注都保存在你的电脑上。FreeRead 不收集遥测数据。

## 数据存在哪里

| 内容 | 位置 |
|---|---|
| 文献库、设置、译文、总结、批注等 | `%APPDATA%\FreeRead`（SQLite 数据库 `freeread.db` 及相关文件） |
| 解析引擎的独立环境、嵌入模型 | 同一数据目录下 |
| API Key | Windows 凭据管理器（系统钥匙串），不写入设置文件 |
| Zotero | 只读；快照模式下先复制 `zotero.sqlite` 到数据目录再读，不会写原库 |

备份时复制整个 `%APPDATA%\FreeRead` 即可（API Key 需要另外重新输入）。

## 什么时候会把内容发出去

只有以下情况会把论文内容发送到你配置的外部服务，而且第一次都会征得你的同意：

| 功能 | 发送什么 | 发给谁 |
|---|---|---|
| 翻译、总结、问答、术语抽取、图谱抽取 | 相关段落文本 | 你在 [大模型服务](/llm-services) 里为该任务选择的服务 |
| 语义索引（选"大模型服务"时） | 段落文本 | 所选服务的嵌入接口；默认的内置本地模型不上传 |
| 远程解析 | PDF 原文 | 你配置的 MinerU / Docling 服务；指向公网地址时需先点"允许上传" |

**设置 › 隐私** 列出你允许过的服务和解析地址，可以随时撤销。使用 Ollama 或本机 / 局域网的解析服务时，内容不会离开本地网络。

下载嵌入模型、安装解析引擎时会访问 Hugging Face（或你设置的镜像）和 Python 包索引（或你选的 PyPI 镜像），只下载，不上传你的文献内容。

**设置 › 关于** 里点“检查更新”时会访问 GitHub 查询最新 Release 并下载安装包；“关于”页还会从 GitHub 读取贡献者列表。只在你打开或点按钮时联网，不发送文献内容。
