# 解析引擎

FreeRead 先把 PDF 解析成统一的结构（段落、标题、公式、表格、图片及其在页面上的位置），重排、翻译、总结、问答都基于这个结构。

| 引擎 | 特点 |
|---|---|
| 快速模式（PyMuPDF） | 内置，秒级完成，不需要 GPU；对双栏、公式、表格的还原有限，扫描版无法处理 |
| MinerU | 质量最好，推荐；本机运行需要下载数 GB，有 NVIDIA 显卡时快很多 |
| Docling | 另一种高质量引擎 |

MinerU、Docling 不随安装包分发，按需安装或连接远程服务，并遵循各自的许可证（MinerU 为 Apache-2.0 加附加条款，Docling 为 MIT）。

## 设置 › 解析

- **高质量解析引擎**：导入后先用快速模式出可读版本，再在后台用高质量引擎升级。"自动"表示 MinerU 可用时升级；也可以选"只用快速模式"或指定引擎。
- **解析设备**：自动 / GPU / CPU，只影响在本机运行的 MinerU 和 Docling；GPU 需要 NVIDIA 显卡。改动从下一次解析开始生效。

## 在本机安装

在 MinerU / Docling 卡片上选 **本机**，点安装。FreeRead 会在数据目录下建一个独立的 Python 环境并安装固定版本的引擎（自动下载 Python 和依赖，体积数 GB，耗时取决于网速），不影响系统里的其他 Python。安装进度显示在底部任务栏。

- **PyTorch**：默认安装 GPU（CUDA）版。检测到 NVIDIA 驱动时按驱动版本匹配；没有显卡时也装 CUDA 版（用 CPU 运行，之后装上显卡驱动不必重装）；GPU 版安装失败时自动改装 CPU 版。
- **PyPI 镜像**：安装处可以选下载 Python 包的源：官方 PyPI、清华、阿里云、中科大、腾讯云，或自定义 simple 索引地址。PyTorch 仍从 PyTorch 官方源下载。

## 使用远程服务

在卡片上选 **API 服务**，填写 Base URL（和可选的 API Key），点 **测试连接**：

- MinerU：云端 `https://mineru.net/api`，或自部署的 `mineru-api`（如 `http://127.0.0.1:8000`），需要 MinerU 4.0 以上。可选质量档位：standard（VLM，推荐）、advanced（最准，最慢）。旧版本里选的 flash / basic 会自动改成 standard。
- Docling：自部署的 `docling-serve`（如 `http://127.0.0.1:5001`）。

指向本机或局域网地址时，PDF 不离开本地网络。指向公网地址时，必须先点 **允许上传** 才会使用；修改 Base URL 后需要重新允许。没允许之前，后台自动升级会跳过这个引擎。

## 单篇重新解析

阅读器顶栏或文献右键菜单的 **重新解析…** 可以对单篇文献换引擎重新解析，已有的译文、总结、批注会尽量迁移。
