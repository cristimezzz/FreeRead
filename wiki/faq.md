# 常见问题

### 运行时提示"Windows 已保护你的电脑"
程序暂未签名，点 **更多信息 → 仍要运行**。见 [安装](/install)。

### 怎么更新到新版本？
0.2.0 起在 **设置 › 关于** 点 **检查更新**。从 0.1.0 升级需要手动下载新版安装包覆盖安装。见 [安装 › 更新](/install#更新)。

### 便携版打开是白屏 / 黑屏
确认系统装有 WebView2 运行时（可从微软官网下载 Evergreen 版），并确认 `freeread-desktop.exe` 和 `freeread-core` 文件夹在同一目录。仍有问题请改用安装包。

### 启动后提示核心服务启动失败或意外退出
界面会显示核心服务（`freeread-core`）错误输出的末尾，请把它附在 Issue 里。常见原因是杀毒软件拦截了 `freeread-core.exe`，可以把安装目录加入信任。

### 从 Zotero 同步没有反应 / 提示连不上
- 使用本地 API 时需要 Zotero 7 正在运行，并在 Zotero 设置里允许本地 API。
- 数据来源为"自动"时，Zotero 没运行会改读数据库快照，需要 **设置 › Zotero** 里的数据目录正确（默认 `~/Zotero`）。
- 没有 PDF 附件的条目能导入，但没有可阅读的内容。

### 重排后版式很乱、公式不对
快速模式对双栏、公式、表格的还原有限。安装 MinerU 或连接远程解析服务后，在阅读器里点 **重新解析**。见 [解析引擎](/parsers)。

### 扫描版 PDF 只能看原版
快速模式不做文字识别，扫描版需要用 MinerU 等高质量引擎解析。

### 翻译提示"no model configured"或没有反应
在 **设置 › 大模型服务** 添加服务并保存 Key，再在 **设置 › 翻译、总结、问答与图谱** 选择翻译使用的服务和模型。用"测试连接"检查 Base URL 和 Key。

### 改了术语表，旧译文没有变
已保存的译文不会自动更新，新术语只对之后翻译的段落生效。

### 图谱抽取失败或图谱很空
- 失败时面板会显示原因；密钥无效、余额不足（如 `HTTP 402`）需要到服务商那里处理。
- 实体很少通常是模型能力或解析质量的问题：换更强的图谱抽取模型，或用 MinerU 重新解析后 **重新抽取**。
- 关系标“出处已失效”：重新解析后这条关系的出处段落没能迁移，重新抽取即可。见 [知识图谱](/knowledge-graph)。

### 想彻底删除数据
卸载时勾选 **删除应用数据**，会删除 `%APPDATA%\FreeRead` 和凭据管理器里的 API Key。已经卸载过的，手动删除 `%APPDATA%\FreeRead`，并在"凭据管理器 › Windows 凭据"里删除 FreeRead 相关条目。见 [隐私与数据](/privacy)。

### 支持 macOS / Linux 吗？
目前只有 Windows 版，其他平台在计划中。
