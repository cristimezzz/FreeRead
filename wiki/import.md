# 导入文献

## 从 Zotero 同步

FreeRead 读取 Zotero 的条目、分类和 PDF 附件，**只读，不会修改 Zotero 的数据**。

在 **设置 › Zotero** 选择数据来源：

| 数据来源 | 说明 |
|---|---|
| 自动（默认） | 先连 Zotero 7 的本地 API；连不上（Zotero 没运行，或没开本地 API）且数据目录里有 `zotero.sqlite` 时，改读数据库快照 |
| 只用本地 API | 需要 Zotero 7 正在运行，并在 Zotero 设置中允许其他应用通过本地 API 通信 |
| 只用数据库快照 | 把 `zotero.sqlite` 复制一份再读副本，Zotero 运行与否都可以 |

Zotero 数据目录默认是 `~/Zotero`，不同时可在设置里修改。

- **增量同步**：之后的同步只读取变化的条目；距上次全量超过 7 天会自动全量一次。设置里的 **完全同步** 可以手动触发全量，补上增量看不到的变化。
- **同步此分类**：在分类树选中一个分类时，同步只处理这个分类（含子分类）。
- 只导入个人库，不含群组库；回收站里的条目不导入；在 Zotero 里删除的条目同步后会从 FreeRead 中移除。
- 使用"链接附件根目录"（相对路径）的链接附件暂不支持。
- 文献右键菜单的 **在 Zotero 中显示** 会跳到 Zotero 中对应的条目。

## 导入 PDF

点 **导入 PDF**（`Ctrl+O`），在文件对话框里选择 PDF。

## 解析

导入后每篇 PDF 会排队解析，底部任务栏显示进度：

1. 先用内置的快速模式（PyMuPDF），几秒内即可阅读；
2. 如果在设置里装好或配好了高质量引擎（MinerU / Docling），再在后台升级，完成后阅读器自动刷新。

扫描版 PDF（没有文字层）在快速模式下无法重排，只能看原版。详见 [解析引擎](/parsers)。

## 批量操作

- 条目左侧有复选框（悬停时出现，有勾选后常显）；`Ctrl` 点击勾选，`Shift` 点击连选。
- 勾选后工具栏显示已选数量，以及 **全选**、**复制引用**、**移除**、**取消**。
- 在勾选的条目上右键弹出批量菜单；`Delete`、`Ctrl+C` 作用于整批。
- 批量移除失败的条目会保持勾选，并提示失败数量。

## 任务列表

底部任务条可以点开，向上浮出全部进行中和排队的任务：进行中的显示百分比和进度条，排队的显示排队位置，前置任务没完成时标“等待前置任务”。点外部或按 `Esc` 关闭。

## 文献库快捷键

| 按键 | 作用 |
|---|---|
| `↑` / `↓`、`Home` / `End`、`PageUp` / `PageDown` | 在列表中移动 |
| `Enter` | 打开选中的文献 |
| `空格` | 勾选 / 取消勾选当前条目 |
| `Shift+↑` / `Shift+↓` | 扩大勾选范围 |
| `Ctrl+A` | 全选 |
| `Ctrl+C` | 复制标题（有勾选时复制所选条目的引用） |
| `Delete` | 移除文献（有勾选时移除整批，会确认） |
| `Ctrl+F` 或 `/` | 聚焦搜索框；在搜索框里按 `↓` 回到列表 |
| `Ctrl+O` | 导入 PDF |
| `F5` | 从 Zotero 同步 |
| `Esc` | 取消勾选 / 清空搜索 / 取消选中 |

## 右键菜单

- 文献上：打开、重新解析…、复制标题、复制引用、复制 DOI、在 Zotero 中显示、移除文献…
- 列表空白处：导入 PDF…、从 Zotero 同步（或同步此分类）、搜索、刷新列表

移除文献只从 FreeRead 中删除，不影响 Zotero 和 PDF 文件本身。
