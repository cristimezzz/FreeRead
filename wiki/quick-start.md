# 快速上手

## 0. 欢迎向导

第一次打开 FreeRead 会进入欢迎向导，依次：

1. **连接一个大模型服务**：选类型、填 Base URL、模型和 API Key，可以当场测试连接；
2. **选择 PDF 解析方式**：只用快速模式，或安装 / 连接 MinerU、Docling；
3. **要从 Zotero 导入现有文献吗？**：确认 Zotero 数据目录后导入。

每一步都可以跳过，也可以点 **跳过向导** 直接进入文献库；之后在 **设置** 页顶部点 **重新打开欢迎向导**。下面第 1、3、5 步在向导里做过的可以跳过。

## 1. 导入文献

- **有 Zotero**：在文献库点 **从 Zotero 同步**（或按 `F5`）。Zotero 7 正在运行时通过它的本地 API 读取；没运行时自动改读 Zotero 数据库的只读副本。在分类树里选中一个分类后，按钮会变成"同步此分类"。
- **没有 Zotero**：点 **导入 PDF**（`Ctrl+O`）选择文件。

导入后每篇 PDF 会先用快速模式解析，几秒内就能阅读。详见 [导入文献](/import)。

## 2. 打开阅读

双击文献（或选中后按 `Enter`）打开阅读器。顶部工具栏可以切换 **原版 / 并排 / 重排** 视图。在重排视图里点击段落，原版视图会高亮对应位置，反之亦然。详见 [阅读器](/reader)。

## 3. 配置大模型服务

翻译、总结、问答和知识图谱需要一个大模型服务：

1. 打开 **设置 › 大模型服务**，点"添加服务"。
2. 选类型（OpenAI 兼容 / Anthropic 兼容端点 / Ollama），填写 Base URL。
3. 填入 API Key，点 **保存 Key**（保存到系统钥匙串），再点 **测试连接**。
4. 在 **设置 › 翻译、总结、问答与图谱** 里选择目标语言和翻译使用的服务；总结、问答、图谱默认沿用，需要时在“按任务指定服务、自动抽取图谱”里分别设置。

详见 [大模型服务](/llm-services)。

## 4. 翻译、总结、提问

- 在重排视图把"翻译"切到 **对照** / **交替** / **仅译文**，可视区域的段落会逐段出现译文。第一次向某个服务发送论文内容时，会先询问你是否允许。
- 点 **翻译全文** 在后台翻译整篇，之后断网也能读。
- 工具栏右侧的 **总结**、**问答**、**术语**、**图谱**、**批注** 打开对应面板。问答是一棵可以分支的问答树，见 [文献问答](/qa)；图谱见 [知识图谱](/knowledge-graph)。

## 5. 想要更好的版式？

快速模式对双栏、公式、表格的还原有限。可以在 **设置 › 解析** 里安装 MinerU（推荐）或 Docling，或连接远程解析服务；之后导入的文献会在后台自动升级。已导入的文献可以在阅读器里点 **重新解析**。详见 [解析引擎](/parsers)。
