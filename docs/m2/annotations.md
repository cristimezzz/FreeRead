# M2-5：高亮批注与导出 Markdown

- 日期：2026-10-20
- 关联：[路线图 M2](../04-roadmap.md)、[架构 §5.3](../01-architecture.md)、[数据模型 annotations](../03-data-model.md)、[IR §8 块映射](../02-document-ir.md)

## 结论速览

| 项目 | 结果 |
|---|---|
| 高亮 | 重排视图里选中原文 → 浮动工具条选颜色（黄、绿、蓝、粉、紫）或"批注"；原文中画成 `<mark>`，有批注的加点状下划线 |
| 批注 | 阅读器右侧"批注"面板：按阅读顺序列出，点引文跳到原文，直接编辑批注（失焦或 Ctrl+Enter 保存），可改颜色、删除；点正文里的高亮会打开面板并聚焦到它 |
| 原版视图 | pdf.js 只渲染画布、没有文字层，有批注的块在左边距画一条对应颜色的竖条 |
| 重新解析 | 按块映射找新块，再用引文在新块里重新定位；块切分变了时在全文里找唯一出现的位置；都找不到标"原文已重新解析"，批注保留 |
| 导出 | 阅读器顶栏"导出"（或批注面板里的"导出"）：总结、高亮与批注、正文、译文（原文下 / 只要译文 / 不要）、问答记录可选；桌面版用保存对话框选路径，由 Core 写文件；浏览器开发模式直接下载 |

## 设计

### 区间

批注存块 `text` 里的字符区间 `[start, end)`，和 Core 的块文本完全一致（含 `⟦EQ1⟧` 这类占位符），另存区间里的原文 `quote`。不选区间（`start`、`end` 都为空）表示整块，接口支持，界面暂时只有文字选区。

重排视图渲染原文时，每个叶子节点带 `data-off`（在块文本里的起始偏移）、`data-len`、`data-kind`（`features/annotations/offsets.ts`）：

- 文本段按高亮切开，每片是 `<span>` 或 `<mark>`，都带自己的偏移；重叠时后来的高亮优先，不嵌套 `<mark>`；
- 行内公式是整个占位符的长度：选区从公式中间开始取公式起点，在公式中间结束取公式终点；
- 译文没有这些属性，落在译文里或跨块的选区不弹工具条。

### 重新解析（`services/annotations.py` `migrate_annotations`）

在 `ParseService._store` 里与译文、总结、问答的迁移同一事务：

1. 块映射到新块：区间里仍是原来的文字 → 不动；否则在新块里找离原位置最近的同一段文字；
2. 映射不到或新块里没有：在全文所有块里找，只出现一次就挪过去；
3. 都找不到：`status=stale`，块 ID 尽量换成映射后的，批注内容不丢；
4. 整块批注只跟随块映射，`quote` 更新为新块文本。

### 导出（`services/export.py`）

- 头部：标题、作者、年份、期刊、DOI（优先用文献库条目的元数据，没有时用 IR 的 meta）。
- 总结：取该语言最新的一份，按模板小节列要点，块引用换成页码 `[p. 3, 5]`。
- 批注：按阅读顺序，`- ==引文== [p. N]`，批注内容缩进在下面；原文已重新解析找不到的写"原文已重新解析"。
- 正文：按阅读顺序；章节标题从 `###` 起；行内公式还原为 `$…$`，其余占位符去掉；公式块 `$$…$$`；表格保留 HTML；图只保留图注（斜体）；列表、参考文献为列表项。高亮写成 `==…==`（Obsidian、Typora 支持；落在公式中间的高亮不标），批注作为 `> **批注**：…` 跟在块后面。
- 译文：`below` 作为引用块放在原文下面（标题写在括号里），`only` 有译文的块只放译文。
- 问答：每个对话的问与答，答案里的 `[b_0012]` 换成页码。

接口：

- `GET /documents/{doc_id}/annotations`、`POST`（201；块不存在、区间越界 → 422）、`PATCH /annotations/{id} {color?, note?}`、`DELETE /annotations/{id}`（204）。
- `GET /documents/{doc_id}/export/markdown?summary=&annotations=&body=&translation=&qa=&lang=` → `text/markdown`。
- `POST /documents/{doc_id}/export/markdown {…同上, path}` → `{path, bytes}`；`path` 必须是已存在目录下的绝对路径。桌面版的 Tauri 权限加了 `dialog:allow-save`。

## 验证

- `core`：246 个测试通过，新增 `tests/test_annotations.py` 6 个：增删改与阅读顺序、区间校验；迁移（原位、按引文重新定位、全文唯一、整块、stale）；真实重新解析后批注仍对得上；高亮标记与占位符还原；导出各选项（批注、正文高亮、译文位置、问答页码、无占位符残留）；API 状态码与写文件。
- 前端：`tsc`、`vitest`（新增 4 个：段偏移、按高亮切分、DOM 选区换算含公式与译文、文件名）通过。
- 浏览器模式（开发版 sidecar + Vite），在评测集的群体表观基因组论文上：
  - 在摘要里选中一段 → 工具条出现在选区上方 → 绿色高亮，库里的 `quote` 与选中文字一致；
  - 点高亮 → 批注面板打开并聚焦输入框 → 写批注、Ctrl+Enter 保存 → 正文高亮出现点状下划线；
  - 原版视图摘要左侧出现绿色竖条；
  - 导出对话框显示各选项；导出的 Markdown 里批注节、正文 `==…==`、译文引用块、批注引用块都正确。

- [ ] 整块高亮（图、表、公式）接口已支持，界面还没有入口。
- [ ] 批注写回 Zotero 笔记（M4）；导出到 Obsidian / Logseq 的专门格式（M4）。
- [ ] 导出的图只有图注，没有图片本身；可以选择把图片一起导出到同名文件夹。
