# ADR-0004：以 Document IR 作为所有功能的公共数据模型

- 状态：提议
- 日期：2026-10-17

## 背景

重排、翻译、总结、问答、知识图谱都需要处理论文内容。如果每个功能各自处理 PDF 文本，会导致定位不一致、无法互相引用、重复解析。

## 决定

定义统一的 Document IR（规范见 [02-document-ir.md](../02-document-ir.md)）：

- 文档由有序的 block 组成，每个 block 有稳定的 `id`、类型、内容和原 PDF 坐标（anchors）。
- 翻译、总结、问答答案、知识图谱关系都只通过 `block_id` 引用原文。
- IR 带 `schema_version`，变更遵循语义化版本。

## 后果

- 正面：任何 AI 输出都可以溯源并在原版 PDF 上高亮；功能之间可以互相引用（如把总结中的一条结论拖进问答画布）。
- 负面：重新解析会改变 block 划分，导致旧的译文和引用失效。
- 应对：block 同时记录 `content_hash`。重新解析后按 content_hash 和位置做新旧块映射，能映射的迁移译文与引用，不能映射的标记为失效。
