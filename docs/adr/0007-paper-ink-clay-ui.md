# ADR-0007：界面改为"纸张、墨色与陶土"设计语言，用自研小组件替换 @material/web

- 状态：已接受（取代 [ADR-0006](0006-material3-ui.md)）；组件实现与视觉在开发分支上被 [ADR-0009](0009-shadcn-ui.md) 取代
- 日期：2026-10-19

## 背景

M1、M2 按 ADR-0006 用 Material 3 + `@material/web` 实现了文献库、阅读器、总结、问答和设置。用下来的问题：

- FreeRead 的主角是论文正文。M3 的大色块容器、tonal 色彩角色、胶囊形状和波纹，让界面比正文更抢眼；种子色一换，整套界面（按钮、选中项、面板底色）都跟着变色。
- 阅读区本来就是自己排版（衬线正文、KaTeX、按块高亮），界面其余部分却是另一套视觉，两边割裂。
- `@material/web` 处于维护模式；组件在 Shadow DOM 里，想改形状、高度、字号只能靠它暴露的 `--md-*` 变量，改不到的地方就只能接受。为了让 React 受控，`src/components/md.tsx` 里已经积累了不少绕路代码（事件统一 `addEventListener`、选项异步加载时手动刷新显示文字、对话框按钮不能用 `form` 属性……）。

我们参照 claude.ai / anthropic.com 的风格做了一版界面稿（[Design 画布](https://claude.ai/artifact/Vq8bDnQK64toCAvBsE5eN8)，含设计基础、启动页与同意弹窗、文献库、阅读器并排 + 对照翻译、总结、问答、问答深色、设置共 8 张），决定换过去。

## 设计语言

- **纸张与墨色**：固定的暖中性色阶做底和字，浅色、深色各一套，不随强调色变化。
  - 浅色：底色 `#FAF9F5`、侧栏 `#F0EEE6`、卡片 / 输入 `#FFFFFF`、分隔线 `#E6E3DA`、主文字 `#141413`、次级 `#3D3D3A`、辅助 `#65645E`。
  - 深色：底色 `#1F1E1D`、侧栏 `#262624`、卡片 / 输入 `#30302E`、分隔线 `#3B3A37`、主文字 `#F3F1EA`、次级 `#D6D3C8`、辅助 `#A6A398`。
- **一个强调色**：预设陶土 `#D97757`（默认）、墨蓝 `#4F74B8`、苔绿 `#6F8546`、石板 `#6B6A63`，外加自定义。强调色只用于指认：当前选中、引用编号、定位高亮、输入框焦点环、进度条。
- **主按钮用墨色**（浅色下深墨底白字，深色下反过来），不用强调色。
- **线条代替阴影**：1px 暖灰分隔线，圆角 8–12px（卡片 12px、按钮 / 输入 8–10px、问答输入卡 16px），几乎不用投影和色块。
- **字体**：展示标题和阅读正文用衬线体 Source Serif 4 + 思源宋体；界面文字用 IBM Plex Sans + 思源黑体；编号、URL 用 IBM Plex Mono。
- **AI 像对话，不像控件**：回答不加气泡，直接排成衬线正文；输入框是一张圆角卡片。
- **动效安静**：只用三档时长（`--dur-fast` 120ms、`--dur` 200ms、`--dur-slow` 280ms）和一条缓动 `cubic-bezier(.2,0,0,1)`，不回弹。用于悬停 / 按下、分段控件底块滑动、侧栏收展、侧边面板与对话框的进出、新内容淡入、定位落点脉冲一次。系统设置"减少动效"时全部归零。
- **阅读区可调宽**：右侧面板（搜索 / 总结 / 问答）和并排视图的原版 / 重排分界都能拖动（也可用 ← / → 微调，双击恢复默认），宽度记在本机。

## 备选方案

1. **保留 `@material/web`，只换令牌**：把暖色阶映射到 `--md-sys-color-*`，形状、字体改 `--md-sys-shape-*` / `--md-ref-typeface-*`。改动最小，但分段按钮的勾选、选择框的浮动标签、开关的尺寸和滑块的数值气泡都还是 M3 的样子；强调色只想用在少数地方，而 M3 组件把 primary 用在几乎所有交互状态上，要逐个组件覆盖；维护模式和 React 绕路代码的问题也都还在。
2. **用 `src/components/` 里的自研小组件替换**：界面稿里需要的控件其实很少——按钮（主要 / 普通 / 幽灵 / 图标）、分段控件、开关、选择框、文本框、对话框、进度条、滑块。它们都能直接用原生元素（`<button>`、`<select>`、`<input>`、`<dialog>`、`<progress>`、`<input type="range">`）加一层样式实现，可访问性由浏览器提供，没有 Shadow DOM，也不需要事件绕路。

## 决定

选择方案 2：移除 `@material/web` 和 `@material/material-color-utilities`，在 `src/components/ui.tsx` 里用原生元素实现小组件，样式全部来自 `src/styles/global.css` 里的令牌。

- **令牌**：`src/app/theme.ts` 不再生成 37 个 M3 色彩角色，只写入 `:root` 上的少量变量：`--bg`、`--bg2`、`--surface`、`--ink`、`--ink2`、`--ink3`、`--line`、`--line2`、`--hover`、`--ok`、`--err`、`--btn`、`--btn-ink`、`--page`，以及 `--accent` 和由它派生的 `--accent-ink`（强调色文字，浅色向黑、深色向白混合）、`--accent-soft`（14% / 22% 透明底）。
- **深浅色、对比度**保留：深浅色切换中性色阶；"中 / 高"对比度把辅助文字、分隔线往主文字方向压，并加深强调色文字。设置项沿用 `appearance.theme_mode`、`appearance.contrast`，强调色仍存在 `appearance.seed_color`（字段名不变，避免改设置文件和 API），默认值改为陶土 `#D97757`。
- **布局**：
  - 应用外壳是 248px 侧栏：品牌、主导航（文献库 / 阅读 / 设置），文献库页下方是分类树，设置页下方是本页各节的锚点。阅读器里侧栏收成 60px 图标栏，把宽度让给正文。
  - 阅读器工具栏：视图、翻译用分段控件，字号是滑块，右侧"搜索 / 总结 / 问答"是带文字的幽灵按钮，打开的那个用强调色浅底标出。
  - 问答面板：提问是浅底小卡片，回答直接排成衬线正文、不加气泡；底部是圆角输入卡，墨色发送按钮。
- **字体打包**：Source Serif 4、IBM Plex Sans、IBM Plex Mono 用 `@fontsource` 打进安装包，离线可用。思源宋体 / 思源黑体体积太大（各数十 MB），优先用系统里已装的思源 / Noto CJK，没有时退到宋体 / 微软雅黑。

## 后果

- 正面：界面退后、正文在前，阅读区和其余界面是同一套视觉；换强调色只影响少数指认元素；组件是原生元素，React 受控简单，可访问性和键盘操作由浏览器提供；少了两个依赖，包更小。
- 负面：分段控件、开关、对话框等要自己维护样式和状态；原生 `<select>` 的下拉列表样式由系统决定，不完全一致。
- 跟进：
  - 自研组件只引用令牌，不写死颜色；新增控件前先看 `src/components/ui.tsx` 里有没有。
  - 观察没装思源字体的 Windows 机器上中文衬线体的效果，必要时按 unicode-range 子集打包思源宋体。
