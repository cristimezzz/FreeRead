# ADR-0012：本地嵌入模型目录与索引切换

- 状态：评审中
- 日期：2026-11-26

## 背景

欢迎向导与检索设置都需要展示可下载的本地模型、文件体积和就绪状态。不同模型生成的向量即使维度相同，也必须分别建立索引。

## 备选方案

1. 保留单一内置模型，用户通过大模型服务配置其他嵌入模型。
2. 由 Core 维护一份本地模型目录，欢迎向导与检索设置使用同一份目录和下载流程。

## 决定

采用 Core 模型目录。每款内置模型固定权重和分词器的版本、大小与 SHA-256。下载沿用持久化任务队列，以模型 ID 去重。应用以当前模型标识区分索引，换用已就绪的模型后重建索引，写入前检查任务仍使用当前模型。

## 后果

用户可以在导入文献时后台下载模型。下载和重建期间可用关键词搜索。切换模型会消耗重新建立向量索引所需的时间，既有配置与模型缓存可继续使用。
