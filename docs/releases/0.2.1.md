FreeRead 0.2.1：首次发布 Linux 版（x86_64），提供 AppImage、deb、rpm 和 AUR 包；功能与 0.2.0 相同。

## 下载

| 文件 | 说明 |
|---|---|
| `FreeRead_0.2.1_x64-setup.exe` | Windows 安装包（推荐）。安装到当前用户目录，不需要管理员权限；缺少 WebView2 时会自动安装 |
| `FreeRead_0.2.1_x64-portable.zip` | Windows 便携版。解压后运行 `freeread-desktop.exe`；需要系统已有 WebView2（Windows 10/11 一般自带） |
| `FreeRead_0.2.1_amd64.AppImage` | Linux 任意发行版，免安装。`chmod +x` 后直接运行，需要 FUSE 2（Ubuntu 上是 `libfuse2` / `libfuse2t64`） |
| `FreeRead_0.2.1_amd64.deb` | Debian、Ubuntu 及其衍生版：`sudo apt install ./FreeRead_0.2.1_amd64.deb` |
| `FreeRead-0.2.1-1.x86_64.rpm` | Fedora、openSUSE 等：`sudo dnf install ./FreeRead-0.2.1-1.x86_64.rpm` |

Arch 从 AUR 安装 [`freeread-bin`](https://aur.archlinux.org/packages/freeread-bin)（例如 `yay -S freeread-bin`）。

- Windows 10/11 x64。安装包和程序**没有代码签名**，首次运行时 SmartScreen 可能提示"Windows 已保护你的电脑"，点"更多信息 → 仍要运行"即可。
- Linux x86_64，需要 glibc 2.35 以上（Ubuntu 22.04、Debian 12、Fedora 36 及更新）和 WebKitGTK 4.1；API Key 保存在 Secret Service（GNOME Keyring / KWallet）里。

## 从 0.2.0 升级

- Windows 在 **设置 › 关于** 里点"检查更新"即可：安装版下载后自动安装并重新打开，便携版下载到"下载"文件夹由你解压替换。文献库、设置和 API Key 都保留。
- Linux 是首次发布，按上表安装。之后的版本同样可以在 **设置 › 关于** 里检查更新：AppImage、deb、rpm 会下载同类包到"下载"文件夹，AUR 用 AUR 助手更新。

## 新增

- **Linux 版**：AppImage、deb、rpm 和 AUR `freeread-bin`。每次构建都在 CI 里安装并启动一遍（Ubuntu 上装 deb 和运行 AppImage、Fedora 上装 rpm、Arch 上打 AUR 包），确认解析服务能随程序启动和退出。
- **使用说明**迁到 [docs.freeread.work](https://docs.freeread.work)，项目主页顶栏加了"文档"入口。
