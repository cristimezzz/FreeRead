FreeRead 0.2.3：新增 macOS 版（Apple 芯片）；新的"原生"界面风格，macOS 和 Windows 上看起来像系统自带的应用，强调色可跟随系统。

## 下载

| 文件 | 说明 |
|---|---|
| `FreeRead_0.2.3_x64-setup.exe` | Windows 安装包（推荐）。安装到当前用户目录，不需要管理员权限；缺少 WebView2 时会自动安装 |
| `FreeRead_0.2.3_x64-portable.zip` | Windows 便携版。解压后运行 `freeread-desktop.exe`；需要系统已有 WebView2（Windows 10/11 一般自带） |
| `FreeRead_0.2.3_aarch64.dmg` | macOS（Apple 芯片）。打开后把 FreeRead 拖进"应用程序" |
| `FreeRead_0.2.3_amd64.AppImage` | Linux 任意发行版，免安装。`chmod +x` 后直接运行，需要 FUSE 2（Ubuntu 上是 `libfuse2` / `libfuse2t64`） |
| `FreeRead_0.2.3_amd64.deb` | Debian、Ubuntu 及其衍生版：`sudo apt install ./FreeRead_0.2.3_amd64.deb` |
| `FreeRead-0.2.3-1.x86_64.rpm` | Fedora、openSUSE 等：`sudo dnf install ./FreeRead-0.2.3-1.x86_64.rpm` |

Arch 从 AUR 安装 [`freeread-bin`](https://aur.archlinux.org/packages/freeread-bin)（例如 `yay -S freeread-bin`）。

- Windows 10/11 x64。安装包和程序**没有代码签名**，首次运行时 SmartScreen 可能提示"Windows 已保护你的电脑"，点"更多信息 → 仍要运行"即可。
- macOS 14 以上，Apple 芯片（M1 及更新）；暂不提供 Intel 版。**未经 Apple 公证**，第一次打开时在 Finder 里右键 FreeRead › **打开**，再在弹窗里点 **打开**；没有"打开"按钮时到"系统设置 › 隐私与安全性"底部点 **仍要打开**。
- Linux x86_64，需要 glibc 2.35 以上（Ubuntu 22.04、Debian 12、Fedora 36 及更新）和 WebKitGTK 4.1。

详见 [安装](https://docs.freeread.work/install)。

## 从 0.2.2 升级

- 在 **设置 › 关于** 里点"检查更新"：Windows 安装版下载后自动安装并重新打开；便携版、AppImage、deb、rpm 下载到"下载"文件夹，由你替换或安装；AUR 用 AUR 助手更新。
- 文献库、设置和 API Key 都保留。升级后界面风格默认是"原生"，强调色保留你原来选的颜色；想要原来的样子，在 **设置 › 外观 › 界面风格** 选 **FreeRead**。

## 新功能

- **macOS 版**：Apple 芯片的 dmg。使用系统原生的红绿灯标题栏，API Key 存在系统钥匙串；**设置 › 关于** 里检查更新后可以 **安装并重启**，自动替换"应用程序"里的旧版。
- **原生界面风格**（**设置 › 外观 › 界面风格**，默认开启）：
  - **macOS**：系统字体，侧栏半透明透出桌面；macOS 26 及更新的版本上侧栏是 Liquid Glass，按钮和分段控件为胶囊形。
  - **Windows 11**：Mica 材质、Segoe UI 字体，按钮、开关、下拉框、菜单、对话框是 WinUI 3 的样子。Windows 10 没有 Mica，背景改为不透明。
  - Linux 没有统一的系统样式，原生与 FreeRead 外观相同。
  - 原来的纸张风格保留为 **FreeRead** 选项。详见 [外观](https://docs.freeread.work/appearance)。
- **强调色跟随系统**：macOS 和 Windows 上可以使用系统设置里的强调色，在系统里改了之后切回 FreeRead 即生效。新安装默认跟随系统。

## 改进

- 阅读器里侧栏的收展动画放慢；macOS 上收起的图标栏加宽，容纳红绿灯按钮，图标随收起放大。
- 并排视图开关侧边面板时，分隔条当帧到位，不再先挤压右栏再跳到新位置；PDF 页面随宽度平滑缩放，停下后再清晰重绘，不再闪白。

## 修复

- 设置页点侧栏锚点后，滚动途中高亮不再在各节之间闪烁；侧栏底部不再出现横向滚动条。

## 其他

- 项目主页在最新 Release 带有 dmg 时显示 macOS 下载；取不到最新 Release 时，下载按钮回退到 GitHub 的最新版本页面，不再指向旧版本。
- 文档站新增 [外观](https://docs.freeread.work/appearance)；常见问题里的支持平台已更新。

## 已知限制

- Windows 程序未签名，macOS 程序未经公证。Linux 只有 x86_64，没有 ARM 版；macOS 没有 Intel 版。AppImage 不会自动加入应用菜单。
- 知识图谱是单篇的，实体不跨文献合并；跨文献问答和文献引用图（M3 后续）尚未完成。
- MinerU / Docling 本机安装需要下载数 GB；没有 GPU 时建议用快速模式或远程服务。
