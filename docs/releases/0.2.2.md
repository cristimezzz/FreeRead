FreeRead 0.2.2：界面改用 shadcn/ui 重新整理，问答和总结的 AI 界面重做；翻译和问答的提示词调整为能命中服务商的前缀缓存，同一篇论文连续翻译、追问时更省钱。

## 下载

| 文件 | 说明 |
|---|---|
| `FreeRead_0.2.2_x64-setup.exe` | Windows 安装包（推荐）。安装到当前用户目录，不需要管理员权限；缺少 WebView2 时会自动安装 |
| `FreeRead_0.2.2_x64-portable.zip` | Windows 便携版。解压后运行 `freeread-desktop.exe`；需要系统已有 WebView2（Windows 10/11 一般自带） |
| `FreeRead_0.2.2_amd64.AppImage` | Linux 任意发行版，免安装。`chmod +x` 后直接运行，需要 FUSE 2（Ubuntu 上是 `libfuse2` / `libfuse2t64`） |
| `FreeRead_0.2.2_amd64.deb` | Debian、Ubuntu 及其衍生版：`sudo apt install ./FreeRead_0.2.2_amd64.deb` |
| `FreeRead-0.2.2-1.x86_64.rpm` | Fedora、openSUSE 等：`sudo dnf install ./FreeRead-0.2.2-1.x86_64.rpm` |

Arch 从 AUR 安装 [`freeread-bin`](https://aur.archlinux.org/packages/freeread-bin)（例如 `yay -S freeread-bin`）。

- Windows 10/11 x64。安装包和程序**没有代码签名**，首次运行时 SmartScreen 可能提示"Windows 已保护你的电脑"，点"更多信息 → 仍要运行"即可。
- Linux x86_64，需要 glibc 2.35 以上（Ubuntu 22.04、Debian 12、Fedora 36 及更新）和 WebKitGTK 4.1。

## 从 0.2.1 升级

- 在 **设置 › 关于** 里点"检查更新"：Windows 安装版下载后自动安装并重新打开；便携版、AppImage、deb、rpm 下载到"下载"文件夹，由你替换或安装；AUR 用 AUR 助手更新。
- 文献库、设置和 API Key 都保留。首次启动会升级数据库（新增缓存命中计量），升级前自动备份为 `freeread.db.bak-<旧版本>`。

## 改进

- **界面**：改用 shadcn/ui 和 Tailwind CSS 重新整理外壳、文献库、设置和欢迎向导；配色改为偏暖的纸色中性色阶（浅色 / 深色）。侧栏在阅读器里收成图标栏，收展动画更顺。
- **AI 界面**：问答卡片、总结进度、任务浮窗重做；问答、总结、图谱里的引用统一，悬停即可看到原文片段。
- **重排视图**：原文与译文上下对照时加了间距和左侧竖线，并排时加分隔线。
- **打开文献更快**：PDF 视图并行读取页面尺寸，长文档首屏等待更短；滚出视野的页面释放画布，长时间滚动内存不再持续上涨；公式渲染加缓存，重排正文延后渲染。
- **前缀缓存**：DeepSeek、通义、Moonshot、OpenAI 等服务会对请求开头重复的部分按更低价格计费。翻译时把规则、标题、摘要和术语表放在每次请求的最前面，同一篇论文的后续段落大部分输入都能命中；问答的追问改为真正的多轮对话，只在末尾追加。详见 [大模型服务](https://docs.freeread.work/llm-services)。
- **短论文问答**：约 3 万 token 以内的论文直接把全文发给模型，不再检索，回答更完整；更长的论文和本地 Ollama 仍只发送检索到的段落。

## 修复

- 本地缓存不再保存格式不对的回复和空的流式回复，避免重试时一直拿到坏结果。

## 其他

- 项目主页的下载按钮自动跟随最新 Release；文档站新增 [更新历史](https://docs.freeread.work/changelog)。
