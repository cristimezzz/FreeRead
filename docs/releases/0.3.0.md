FreeRead 0.3.0 改进了 Zotero 同步、PDF 解析和重排阅读，并增加了应用内的数据清理。

## 改进

- **Zotero 同步**：自动模式在本地 API 不可用或同步中断时改用数据库快照。缺少本地 PDF 的条目保留题录，列表显示「无 PDF」，并跳过解析。补齐附件后可再次同步，必要时执行完全同步。
- **解析并发**：本机 MinerU 和 Docling 共享并发上限，默认 1，可在「设置 › 解析 › 更多选项」调整。API 模式独立并发 8，MinerU API 每个 FreeRead 进程在任意连续 60 秒内最多提交 10 个文件，超出的任务自动等待。
- **重排阅读**：解析结果包含子图位置时保留子图布局，宽表可横向滚动。
- **任务进度**：底部任务栏和展开列表显示文献任务对应的标题，排队时也可查看。
- **大模型服务**：新建服务的默认最大并发从 4 提高到 8，已有服务保留已保存的并发值。
- **应用数据**：在「设置 › 数据」可以分别删除文献、笔记与设置，API Key，以及本机解析引擎与模型。删除成功后应用自动重启。

## 下载

| 文件 | 说明 |
|---|---|
| `FreeRead_0.3.0_x64-setup.exe` | Windows 10／11 x64 安装包，推荐 |
| `FreeRead_0.3.0_x64-portable.zip` | Windows 10／11 x64 便携版，解压后运行 `freeread-desktop.exe` |
| `FreeRead_0.3.0_aarch64.dmg` | Apple 芯片 Mac，需要 macOS 14 或更新版本 |

Linux 需 glibc 2.35 或更新版本。Windows 程序暂未签名，macOS 程序暂未公证。各平台的首次运行步骤见 [安装说明](https://docs.freeread.work/install)。

## 升级

在 **设置 › 关于** 点 **检查更新**。Windows 安装版和 macOS 支持下载后安装并重新打开应用。Windows 便携版、Linux AppImage、deb 和 rpm 下载后手动替换或安装。升级会保留文献库、设置和 API Key。

从 0.1.0 升级，或 macOS 上的旧版无法启动时，直接下载对应的安装包覆盖安装。详见 [安装 › 更新](https://docs.freeread.work/install#更新)。
