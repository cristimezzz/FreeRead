FreeRead 0.2.0：路线图 M3 的第一部分——每篇论文的知识图谱和问答树；另外新增欢迎向导、应用内检查更新和文献库批量操作。

## 下载

| 文件 | 说明 |
|---|---|
| `FreeRead_0.2.0_x64-setup.exe` | 安装包（推荐）。安装到当前用户目录，不需要管理员权限；缺少 WebView2 时会自动安装 |
| `FreeRead_0.2.0_x64-portable.zip` | 便携版。解压后运行 `freeread-desktop.exe`；需要系统已有 WebView2（Windows 10/11 一般自带） |

仅支持 Windows 10/11 x64。安装包和程序**没有代码签名**，首次运行时 SmartScreen 可能提示"Windows 已保护你的电脑"，点"更多信息 → 仍要运行"即可。

## 从 0.1.0 升级

- **安装版**：直接运行新的安装包覆盖安装，文献库、设置和 API Key 都保留。
- **便携版**：解压新的 zip，替换旧的 `freeread-desktop.exe` 和 `freeread-core` 文件夹。
- 0.1.0 没有检查更新功能，这一次需要手动下载；从 0.2.0 起可以在 **设置 › 关于** 里检查并下载新版本。

## 新功能

- **知识图谱**：阅读器侧栏新增"图谱"面板，按章节抽取一篇论文的核心实体（方法、数据集、指标、任务等）和关系。每条关系都带出处段落，摘句和数值会与原文核对，对不上的数值整条丢弃。图谱以 3D 链接云图显示，可展开铺满阅读区；点节点或关系名查看详情和出处，并跳回原文。重新解析后出处按段落迁移，迁移不上的标"出处已失效"。可在设置里打开"建立语义索引后自动抽取图谱"（默认关）。
- **问答树**：单篇问答改为全卡片式，卡片铺满阅读区，标题由模型概括。每张卡片可以**追问**、**重答**、**另起**新话题，选中回答里的文字可以**就此追问**；每一支只带自己的上文，分支互不干扰。删除卡片会连同它下面的分支一起删除。
- **欢迎向导**：新安装时引导配置大模型服务、解析服务，并询问是否从 Zotero 导入；每一步都可跳过，也可以在设置里重新打开。
- **设置 › 关于**：显示版本和贡献者；点"检查更新"查询 GitHub Release，下载后按 sha256 校验。安装版下载完自动安装并重新打开，便携版下载到"下载"文件夹由你解压替换。只在点按钮时联网。
- **文献库批量操作**：条目左侧复选框，Ctrl 点选、Shift 连选、Ctrl+A 全选；批量复制引用、批量移除，右键菜单和 Delete / Ctrl+C 作用于整批。
- **任务列表**：点底部任务条展开浮窗，列出全部进行中和排队的任务及进度。
- **设置页**：按重要性重排分节，次要选项默认折叠（里面有改过的值时自动展开）；每个大模型服务可设置"最大并发"（默认 4），翻译、总结和图谱抽取的并行度都跟随它。
- **本机解析引擎**：安装 MinerU / Docling 时默认装 GPU 版 PyTorch，失败再退回 CPU 版；可选 PyPI 镜像（清华、阿里云、中科大、腾讯云或自定义）。
- **MinerU API**：质量档位只保留 standard / advanced（默认 standard），旧设置自动升级。

## 修复

- 卸载时勾选"删除应用数据"现在会真正删除 `%APPDATA%\FreeRead` 和凭据管理器里的 API Key；不勾选或更新安装时保留。
- 同一毫秒内生成的 ID 可能乱序，影响任务队列和问答节点的顺序。
- 前端主包从约 1.1 MB 拆到约 220 kB，PDF、公式和 3D 图谱按需加载。

## 已知限制

- 未签名；只有 Windows 版。
- 知识图谱是单篇的，实体不跨文献合并；跨文献问答和文献引用图（M3 后续）尚未完成。
- 图谱抽取和问答的效果取决于所选模型；没有建立语义索引时问答只用关键词检索。
- MinerU / Docling 本机安装需要下载数 GB；没有 GPU 时建议用快速模式或远程服务。
