FreeRead 的第一个公开版本：本地优先的学术文献阅读工具，完成了路线图的 M1（导入、重排、翻译）和 M2（总结、问答、批注）。

## 下载

| 文件 | 说明 |
|---|---|
| `FreeRead_0.1.0_x64-setup.exe` | 安装包（推荐）。安装到当前用户目录，不需要管理员权限；缺少 WebView2 时会自动安装 |
| `FreeRead_0.1.0_x64-portable.zip` | 便携版。解压后运行 `freeread-desktop.exe`；需要系统已有 WebView2（Windows 10/11 一般自带） |

仅支持 Windows 10/11 x64。安装包和程序**没有代码签名**，首次运行时 SmartScreen 可能提示"Windows 已保护你的电脑"，点"更多信息 → 仍要运行"即可。

便携版只是免安装：文献库和设置仍保存在 `%APPDATA%\FreeRead`，API Key 仍保存在系统凭据管理器，和安装版共用。

## 功能

- **文献库**：从 Zotero 7 导入分类和条目（Zotero 运行时走本地 API，没运行时读数据库快照），增量同步；也可以直接导入 PDF。右键菜单和键盘快捷键管理文献。
- **阅读器**：原版（pdf.js）、重排、并排三种视图，重排与原版双向定位；公式（KaTeX）、表格、图片按原样渲染；文内混合检索（关键词 + 语义）。
- **解析引擎**：内置 PyMuPDF 快速模式，导入即可读；可在设置里一键安装 MinerU / Docling 到本机独立环境，或连接 mineru.net、自部署的 mineru-api / docling-serve，换引擎重新解析单篇文献。
- **翻译**：块级翻译，可视区域优先、公式和引用占位保护；原文 / 对照 / 交替 / 仅译文四种显示；整篇后台翻译，之后离线可读；术语表自动抽取并可编辑，翻译时注入。
- **AI 总结**：分层总结、结构化模板，每条结论带可跳转的原文引用。
- **问答**：针对单篇论文提问，答案中的引用经过校验，点击跳到原文。
- **批注**：在重排视图选中文字高亮、写批注；重新解析后按原文重新定位；总结、批注、正文和译文一起导出为 Markdown。
- **大模型服务**：OpenAI 兼容接口（OpenAI、DeepSeek、通义、Moonshot、vLLM 等）、Anthropic 兼容端点、本地 Ollama；翻译 / 总结 / 问答 / 嵌入可分别指定服务和模型；结果缓存，用量记录。
- **隐私**：数据都在本机 SQLite；API Key 存系统钥匙串；第一次向某个服务发送文档内容前会征得同意。

## 已知限制

- 未签名；只有 Windows 版，没有自动更新。
- MinerU / Docling 本机安装需要下载数 GB，在安装版上没有完整实测过；没有 GPU 时建议用快速模式或远程服务。
- M1 的"3 分钟内看到译文"验收用的是本地 mock 服务，真实服务的速度取决于所选模型。
- 知识图谱、跨文献问答（M3）尚未开始。
