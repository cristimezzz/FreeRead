# M3 问答树（单篇）

单篇问答从线性对话改为一棵问答树，并且是全卡片式的：打开问答时卡片铺满阅读区，每一问一答是一张卡片，卡片标题由模型概括；每张卡片都可以追问、重答或另起一张，选中回答里的文字可以就此追问。交互参考 ai.explore.poker 的卡片式对话（子卡片 = 深入，同级卡片 = 新话题，分支卡片 = 重做同一轮，点高亮词派生新卡片）。M2 的检索、上下文组装、引用校验都不变（见 [m2/qa.md](../m2/qa.md)）。

## 模型

一个节点是一问一答（`qa_nodes`），`parent_id` 组成树；一个对话可以有多个根。四种操作只是新节点挂的位置不同：

| 操作 | 父节点 | 问题 | 其他 |
|---|---|---|---|
| 追问 | X | 新问题 | — |
| 重答 | X 的父节点 | 与 X 相同 | 不使用 LLM 缓存（否则拿回同一个答案） |
| 另起 | X 的父节点（X 是根时为新话题） | 新问题 | — |
| 就此追问 | X | 新问题（预填「选段」是什么意思？） | `anchor = {"text": 选中的文字}` |

## 上下文

- 历史只取新节点的**祖先链**（最近 `HISTORY_TURNS=3` 轮，去掉引用标记、每个回答截 600 字），兄弟分支互不可见。
- 检索查询 = 问题 + 父节点问题 + 选段。
- 提示词 `qa_answer@3`：历史标为"此前这一支的对话"，有选段时写明"用户在上一回答中选中了这段文字并就此追问：「…」"。

## 卡片标题

同一次调用里生成，不额外花钱：提示词要求回答后另起一行写 `标题：<不超过 12 个字>`。服务层（`_split_title`）只认最后一行的 `标题：` / `Title:`（容忍 `**标题**`），取出后存进 `qa_nodes.title`（截到 16 个字），回答里不留这一行；流式显示时前端也把这一行藏起来。模型没写标题行时标题为空，卡片退回显示截短的问题（M3 之前的老节点也是这样）。对话标题取第一张卡片的标题。

## 接口

- `POST /qa/sessions/{id}/ask` 新增 `parent_id`（`null` 为新的根）、`anchor`（≤500 字）、`regenerate`。`parent_id` 不在该对话里时返回 `error{code: bad_request}`。前端总是显式传 `parent_id`。
- `DELETE /qa/nodes/{node_id}`：删除节点及其整棵子树（外键是 `ON DELETE SET NULL`，所以由服务层收集子树一起删）。
- `GET /qa/sessions/{id}` 仍返回按创建时间排好的扁平节点列表，前端自己建树（`features/qa/tree.ts`）。

## 界面

全卡片式（`QaBoard.tsx` / `QaCanvas.tsx` / `QaCard.tsx`），没有单独的问答栏：

- 打开"问答"时卡片画布铺满阅读区（不占右侧面板）。左上角浮着工具栏：对话选择、新对话、新话题、适应窗口、删除对话、关闭。
- 卡片按整齐树布局排开（`tree.ts`，像素布局，卡片大小不一：子树宽 = max(自身宽, 子树宽之和)，节点居中于子树，每层高取最高的卡片）。没有引入 React Flow：节点不多，手写布局更贴合 ADR-0007 的样式。
- 收起的卡片只显示 AI 标题；点一张就地展开（其余收起）：选段引文、问题、带引用编号的回答、重答 · 另起 · 删除分支，以及卡片里的输入框（追问这张卡片）。展开的卡片撑开所在的列和行，周围的卡片让位。
- 另起 / 新话题时出现一张虚线草稿卡片（与那张卡片同级，或作为新的根），输入框在草稿卡片里；还没有任何卡片时只有一张草稿卡片。提问中的那张卡片在它的位置上流式显示。
- 在空白处拖动平移、滚轮缩放；展开卡片里可以选字，滚轮滚动卡片内容（按住 Ctrl 仍是缩放）。换一张展开的卡片时把它移进视野。
- 在回答里选中文字浮出"就此追问"；父卡片回答里子卡片的选段加强调色下划线，点它打开那张卡片（`anchors.ts` 在去掉引用标记的文本上按词匹配）。
- 点引用编号：问答先藏起来、跳到原文；阅读区底部的"回到问答"（或再点工具栏的"问答"）回到原来的卡片。

## 迁移

`0011_qa_tree`：`qa_nodes` 加 `anchor`（JSON，可空）、`title`（TEXT，默认空）和索引 `(session_id, parent_id)`。M2 的对话本来就是一条链（`parent_id` 指向上一轮），升级时把每个对话里除第一轮外 `parent_id` 为空的轮次接到前一轮上，老对话显示为单支的树。

## 以后

固定原文片段（`pinned_blocks`）、拖入图谱实体（`subgraph`）、手动摆放节点（`position`）、祖先链过长时做摘要，都还没做。
