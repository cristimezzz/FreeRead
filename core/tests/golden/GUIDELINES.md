# Golden 标注规范（M0）

golden 由 `scripts/m0_golden.py` 自动生成：MinerU 与 Docling 的块在同页上按 IoU ≥ 0.5 聚类，两者类型一致的簇直接采纳（`consensus`）；其余簇（类型冲突、只有一个引擎检测到）由 Claude 对照页面图像逐页复核，修正记录在 `corrections/<doc_id>.yaml`，复核后的块来源记为 `claude_review`。文本取自 PDF 文本层（扫描页除外），LaTeX 取引擎结果中的 medoid。

复核时遵循以下规则：

1. **参考文献**：参考文献列表中的每一条都是 `reference_entry`（不是 `list_item`）。
2. **标题**：首页的论文题目是 `title`；期刊栏目名（"Article"、"letters to nature"）、期刊名和刊头不算 `title`，按页眉处理并删除。
3. **页眉页脚**：页眉、页脚、页码、期刊刊头、DOI/版权行等版面装饰一律删除（IR 不收录）。
4. **脚注**：页面底部的作者单位、通讯作者、收稿日期、致谢小字、表注都记为 `footnote`；正文段落即使字号小也记为 `paragraph`。
5. **图**：**一个图注对应一个 `figure`**，框住整张图（含全部子图与图例），因为重排阅读时整张图与图注一起显示。引擎把一张图切成多块（按子图或图例拆分）时，保留覆盖整图的那一块，其余删除；都不覆盖整图时用 `add` 补一个整图框。子图标号（A、B…）、图内文字不单独成块。二维码、"Check for updates" 等装饰图标删除。
6. **图注 / 表注**：以 "Fig." / "Figure" / "Table" / "图" / "表" 开头的说明文字是 `caption`，跨栏分成两块的图注保留两块。
7. **段落粒度**：以视觉上的段落为单位（首行缩进或段间距分隔）。两个引擎粒度不同时，保留与视觉段落一致的那一侧，删除另一侧。
8. **标题粒度**：章节标题单独成块（`heading`），不与后面的正文合并。
9. **公式**：独立成行的显示公式记为 `equation`，含编号；行内公式不单独成块。
10. **其他**：作者行、关键词、期刊栏目框等无法归类的内容记为 `other`；作者姓名与单位行记为 `author_info`。
11. **扫描页**：扫描页上的块同样按上述规则；文本取引擎 OCR 结果的 medoid，不做逐字校对。

已知局限：golden 来自 MinerU 与 Docling 的检测框，两者都漏检的块不在 golden 中（复核时只补明显漏掉的整块）；PyMuPDF 未参与共识，因此对它相对更公平；含公式类样本以生物论文为主，公式数量少。
